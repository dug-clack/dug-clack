# db_viewer

PostgreSQL 테이블 내용을 PC와 모바일 브라우저에서 조회하는 **읽기 전용 뷰어**입니다.
DB 주소(호스트/도메인), 포트, DB 이름, 계정, 비밀번호, SSL 모드는 앱 화면에서 직접 입력합니다.

## 실행

```bash
npm install
npm start            # http://<서버IP>:3000
```

휴대폰에서는 같은 네트워크에서 `http://<서버IP>:3000` 으로 접속합니다.
브라우저 메뉴의 "홈 화면에 추가"를 쓰면 앱처럼 실행됩니다(PWA manifest 포함).

> 브라우저는 PostgreSQL에 직접 접속할 수 없으므로, 이 Node 서버가 DB 연결을 중계합니다.
> 서버는 DB에 접근 가능한 곳(사내망, DB 서버 근처 등)에 두세요.

### 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 웹 서버 포트 |
| `HOST` | `0.0.0.0` | 바인드 주소 |
| `ALLOWED_HOSTS` | (없음) | 접속 허용할 DB 호스트 목록(쉼표 구분). 지정 시 그 외 호스트는 거부 |
| `SESSION_IDLE_MIN` | `30` | 미사용 세션(DB 풀) 자동 종료 시간(분) |
| `STATEMENT_TIMEOUT_MS` | `15000` | 조회 쿼리 타임아웃 |

## 기능

- 연결 정보 입력 및 이 기기에 저장(비밀번호 저장은 선택), 여러 연결 프로필 전환
- 스키마별 테이블/뷰/구체화 뷰 목록, 추정 행 수, 목록 검색
- 페이지 단위 조회(50~1,000행), 컬럼 헤더 클릭 정렬(`˄` 오름차순 / `˅` 내림차순)
- 전체 컬럼 또는 특정 컬럼 대상 텍스트 검색
- 스프레드시트형 표: 1px 셀 구분선, 줄무늬 행, 고정 헤더, 행 번호 + 식별 컬럼(PK, 없으면 첫 컬럼) 고정
- 정렬 규칙: 숫자 우측(정수 `59,715`, 소수 `59,715.20`), 날짜·불리언·enum·짧은 코드 가운데, 긴 텍스트 좌측
- 다중 셀 선택(마우스 드래그, Shift+클릭/화살표, 행 번호 클릭, `#` 클릭 = 전체) 후 Ctrl/⌘+C 또는 [복사] 버튼으로 TSV 복사 → 엑셀/구글 시트에 붙여넣기 가능. 선택 범위 합계 표시
- 모바일: 표 구조 유지 + 가로 스크롤, 테이블 목록은 서랍 메뉴, [범위선택] 토글로 터치 드래그 선택
- 행 상세 보기(더블클릭 / Enter / [상세]): 긴 텍스트·JSON 전체 확인, 위·아래 행 이동

## 안전장치

- 모든 조회는 `BEGIN READ ONLY` 트랜잭션 + `statement_timeout` 안에서 실행됩니다.
- 사용자가 SQL을 직접 실행하는 기능은 없으며, 테이블/컬럼 식별자는 카탈로그에서 확인 후 인용 처리합니다.
- 비밀번호는 서버 메모리의 연결 풀에만 보관되고, 브라우저에는 무작위 세션 토큰만 전달됩니다.
- 운영 DB에는 **SELECT 권한만 가진 전용 계정** 사용을 권장합니다.
- 인터넷에 공개할 경우 HTTPS 리버스 프록시(nginx 등)와 접근 제어를 앞단에 두세요.

## 디자인 메모

사내 오피스 웹앱 디자인 가이드(밝은 테마, 녹색=데이터/선택, 주황=입력/설정, 10–12px 고밀도, 2px 입체 컨트롤, 모서리 ≤ 5px)를 따릅니다.

예외: 이 앱은 읽기 전용이므로 "붙여넣기"는 검색 입력란에서만 지원하고 표 셀로의 붙여넣기(데이터 수정)는 제공하지 않습니다.
